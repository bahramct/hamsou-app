# مرجعِ افکت‌ها — مودالِ اشتراک‌گذاری (سمپلِ تأییدشدهٔ مالک)

> منبع: DECISION-054. مالک یک سمپلِ HTMLِ مستقل را «از هر نظر تأییدشده» معرفی کرد و
> خواست افکت/انیمیشن‌هایش به‌عنوان «استانداردِ طلاییِ کارت/مودالِ اشتراک» به خاطر
> سپرده و مستند شود. پیاده‌سازیِ همسو این افکت‌ها را به توکن‌های دیزاین‌سیستم
> (`globals.css`) منتقل کرده است؛ این سند «چرا و چگونه»ی آن‌هاست تا کارت‌های
> اشتراکِ آینده (پروژه، همسوگرام، …) همین حس را بازتولید کنند.

## فلسفه
شیشهٔ گرم + کاغذ + موشنِ آرام. هیچ افکتِ پُرسروصدا؛ هر حرکت «ورود/استقرار» را روایت
می‌کند نه «جشن». این دقیقاً هم‌خانوادهٔ اتمسفرِ DECISION-051 است.

## توکن‌های کلیدی (هم‌ارزِ همسو)
- منحنی‌ها: `--ease-expo: cubic-bezier(0.19,1,0.22,1)` (حرکت‌های کلیدی)، `--ease-calm: cubic-bezier(0.25,0.46,0.45,0.94)` (محو/رنگ).
- شیشهٔ مودال: `rgba(255,255,255,0.86)` + `blur(34px) saturate(140%)` + بوردرِ مویی + `inset 0 1px 0 rgba(255,255,255,0.65)` (های‌لایتِ بالا) + سایهٔ دولایه.
- شیشهٔ کاشی/دکمه: `rgba(255,255,255,0.62)` + های‌لایتِ inset؛ روی hover کمی پررنگ‌تر + لیفت.

## افکت‌ها (نگاشتِ سمپل → کلاسِ همسو)
| افکتِ سمپل | شرح | کلاسِ همسو (`globals.css`) |
|---|---|---|

| `.modal` ورود | `translateY(18px) scale(.97)` → `0/1` با `--ease-expo` | `.sharem-panel` |

| دکمهٔ بستن | کاشیِ گردِ شیشه‌ای، hover = `rotate(90deg)`، active = `+scale(.92)` | `.sharem-close` |
| پیش‌نمایشِ تصویر | sweepِ shimmer روی hover: `translateX(-120% → 120%)` در ~۹۵۰ms | `.sharem-preview` + `.sharem-preview-img::after` |

## نکاتِ مهمِ پیاده‌سازی
- **تصویرِ قابل‌دانلود** سمتِ سرور با `next/og`/Satori ساخته می‌شود (نه canvasِ کلاینت مثل سمپل): دترمینیستیک، فونتِ فارسی از دیسک، قابلِ تأییدِ تصویری. «شکلِ» نمودار = SVGِ بدونِ متن (`<img>`/resvg)؛ متن/برچسب با Satori. هیچ `var()`/`backdrop-filter` در تصویر.
- **همهٔ اعداد** در تصویر باید بدونِ جداکنندهٔ هزارگانِ سال باشند (`noGroup` — ICUِ Node سال ۴‌رقمی را گروه می‌کند).
- **متنِ دکمه‌ها هرگز عوض نمی‌شود** (DECISION-053): حین کار فقط `<Spinner>`؛ نتیجه با `toast`. سوییچ‌های حالت مستثنا.
- **توسعه‌پذیری:** آرایهٔ `TARGETS` در `ShareModal.tsx` نقطهٔ افزودنِ «شبکهٔ همسو»ی آینده است (یک عضوِ جدید).
